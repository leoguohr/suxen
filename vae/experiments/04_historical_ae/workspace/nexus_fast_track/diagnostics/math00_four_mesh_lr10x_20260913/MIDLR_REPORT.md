# 四 mesh LR 倍率筛选收口：MidLR 3×

## 结论

在这个共同父 checkpoint、共同 Adam/RNG、逐步共同 ε 的 400-update 对照中，答案是 **可以**：MidLR 保留并实际超过了 HighLR 的加速收益，同时消除了本轮观测到的 10× 明显震荡和旧样本退化。

这不是因为“裁剪更少”而判成功。主要证据是：

1. MidLR 在 step200 的新增结构恢复已大致达到或略超过 Control step400；到 step400，两条新 mesh 的 Edge/Face TP 和 GT Face 候选覆盖率均超过 Control 与 HighLR。
2. 同一 50 组监控噪声的 mean Soft4 从共同起点 0.529687 降至 0.497460；Control 为 0.513635，HighLR 为 0.507080。
3. MidLR 的旧两条在全部 μ/固定 ε 检查点、step0/100/200/400 的 50 组噪声、以及末尾额外 50 组 unseen 中均严格保持。HighLR 曾在 μ step10/50、固定 ε step50 和噪声 step100 出现旧样本错误。
4. HighLR 的逐步 loss 尖峰在 MidLR 中消失：相邻步 reconstruction 差分标准差从 0.003672 降至 0.0000321，最大单步上升从 0.03203 降至 0.0000631；大于 1e-4 的上升步由 93 降至 0。

因此本轮倍率筛选以 MidLR 为当前最佳分支收口，不继续自动扫 5×、7×、20×。这组结果也不触发“3× 只有很小收益”的前提。

## 实际更新尺度与震荡

MidLR 相对 Control 的每步相对参数更新中位数为：Encoder/μ 2.19×、Decoder body 2.19×、Edge head 2.18×、Face head 2.25×；logvar 为 0.82×。因此名义 3× 被 global clip 压成约 2.2× 的实际 E/D/heads 更新，但仍形成了清楚的结构学习加速。

裁剪统计只解释机制，不单独构成成功判据。真正支持 MidLR 的是结构恢复、候选覆盖、同监控集学习趋势和旧样本严格保持同时改善。

## 边界

- 两条新增 mesh 在 step400 仍有大量 FP/FN，四条并未同时严格全对；本轮没有把这一点伪装成成功。
- 这是同一父 checkpoint 上的一条配对轨迹和四个训练 mesh，不等于更大数据分布上的最终超参数证明。
- 534 点 mesh 的 Face TP/coverage 提升伴随 Face FP 增加，后续不能只看总体 F1，也不能说所有结构错误都改善。
- 当前证据足以回答本轮唯一问题并结束倍率扫描；若要将 3× 升为长期默认，下一步应扩展到更多新增 mesh 或独立训练 RNG 复核，而不是继续扫更高倍率。
