# 逆向网络核验：按老师的 overfit 门槛

结论：推理功能层面基本逆向成功；本轮真实加载老师权重后，最终 AE 和 A100 上两组完整串联都达到老师的相应门槛。这里的成功是可运行、具有接近老师结果的训练集重建能力，不是原源码逐行恢复，也不是从随机初始化重新训练成功。

老师原始预测也在本次独立复算：AE Face F1=0.9991923180；给定GT顶点的Flow两组为0.9916329285、0.9901934323；完整串联为0.9910931174。它们与本轮重建网络不是同一批输出。

这不是无条件跨平台精确复现：下载包里已有CPU串联Face F1=0.9894037356和0.9928912085，本轮已从数组重算确认，第一组未到0.99。本次GPU两组都通过不抹去这个事实。CPU/GPU、PyTorch版本、随机数流及未确认的前向细节均可能影响结果；没有用追加训练、挑选更多种子或改阈值来匹配数字。

## 逆向恢复到哪一层

已确认：现有权重兼容的网络尺寸、可执行前向、点数预测、文本坐标先验、点采样、顶点条件拓扑Flow、AE解码和实际mesh评价均能连通，且本轮达到老师门槛。AE比原老师结果少恢复1个Face；新GPU串联的预测集合也不等于老师保存集合。

尚未确认：原始attention头数/RoPE布局/时间编码等是否唯一正确，所有中间激活是否一致，原dropout与后验clamp，训练负例精确顺序、完整loss系数、optimizer与RNG历史。权重形状不能唯一确定这些内容。`objectives.py`只是重建的可微组件；其空组规则、KL归约、点损失系数不等于已找回老师原训练器。

## 与咱们CAD50 B2500的有效实现比较

这里比较原512维CAD50支路，不把老师模型当成原固定100条项目的结果。两边目标来自同一训练缓存：50条、2872顶点、8364条GT边、5576个GT面。

| 项目 | 老师权重对应的复建版 | 咱们CAD50/B2500 |
|---|---|---|
| 输入编码 | XYZ加6频段sin/cos，39维，共享39→128投影 | 顶点XYZ、面重心XYZ分别3→512线性投影，无Fourier |
| Encoder图 | 顶点与面重心二部图，mean聚合 | 相同类型的二部图与mean聚合 |
| Graph更新 | 原h聚合→self/neighbor线性→LayerNorm→GELU→残差 | h先LayerNorm→self/neighbor线性→SiLU→残差；邻居投影含bias |
| Encoder | 8组Graph+Transformer，宽128，4头 | 12组Graph+Transformer，宽512，8头；配置24指Graph与Transformer各算一层 |
| latent | 每顶点64维；本次AE评价取μ | 每顶点512维；训练/评价μ，sampling关闭、KL=0、logvar冻结 |
| Decoder | 8层，宽128；每层attention+GELU FFN（128→512→128） | 16层，宽1024；每层attention残差，无FFN |
| 输出head | LN后128→64，再拆Edge32/Face32 | 最终LN后两个1024→32线性head，再逐mesh中心化 |
| 参数规模 | AE 3,476,032个参数 | 模型张量状态约112,475,200个元素，包括冻结分支；约1.12亿量级 |
| 评分 | spacetime32=16space+16time，Edge距离平方差、Face Gram面积差，>0判正 | 相同评分函数族；额外固定Edge scale≈0.93061，Face scale≈0.39804及面积因子0.25 |
| 训练目标与Face负例 | 报告为balanced BCE、早期KL=1e-6；动态三角候选/随机负例，完整训练器未找回 | B2500为fully-differentiable Soft4；Face固定13946个pool候选，全部Edge pair，50条累积一次更新 |
| 训练过程 | AE历史累计130000步，扩层、困难样本加权采样、阶段重置AdamW等有记录 | B2500累计2500次全50条更新，继承Adam；两种“步”不能直接比较训练量 |
| 生成链路 | 点数+文本先验/点Flow→10层拓扑Flow→AE Decoder已可执行 | 本轮比较对象是固定坐标输入的512维拓扑AE，不是已达到同等质量的点→拓扑生成链路 |

正比例scale和中心化在精确数学下不改变这一spacetime评分的判正符号，但会影响数值与训练梯度。单个64维输出层拆成两个32维head，与两个独立线性head拼接在函数形式上等价；“一个head还是两个head”本身不是容量差距的证据。

最值得关注的实际结构差别是输入Fourier特征、Decoder是否有FFN，以及Graph归一化/激活次序。它们是已证明存在的差别，不是已证明的失败根因。老师训练预算、采样与loss也不同，不能仅凭它更小且F1更高，就认定原模型某一处必然有bug。

同一CAD50目标，咱们B2500已有完整评价Face F1=0.3501810501；老师AE本次为0.9991024951。这证明现有checkpoint的重建质量差距很大，不是同预算、同训练协议的架构优劣实验。

点网络还有一个范围区别：最终预测由学习的文本坐标先验加`1.2198240256e-5 × 原去噪分支`组成。老师原报告明确称为对50条训练prompt的记忆。模型调用只接收缓存文本向量与噪声；这不证明新文本泛化，也不能把点精度全算作原去噪器的能力。
