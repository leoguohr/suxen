# 小 β 接入对照：两支各 200 个实际更新

**本轮通过。** 从同一 math00_fresh_eps_step200 出发，β=0 与 β warmup→1e-4 两支在 step50、100、200 均满足 μ 四项严格全对、监控噪声50/50；末尾另50组新噪声也各50/50。五组参数每一步都有非零实际更新，采样扰动非零。

| 指标 | 起点 | β=0 step200 | β→1e-4 step200 |
|---|---:|---:|---:|
| 监控50组平均重建 Soft4 | 0.009986139 | 0.008145750 | 0.008285619 |
| KL total | 10.305924416 | 10.314951897 | 9.732486725 |
| KL mu | 0.817132115 | 0.817018151 | 0.817025006 |
| KL sigma | 9.488792419 | 9.497933388 | 8.915461540 |

KL 分支总 KL 下降约5.56%，几乎全部来自 Kσ（9.48879→8.91546）。Kμ 与无 KL 对照几乎一致；末尾甚至比对照高约6.85e-6，因此不能把两支共同的微小 Kμ 下降归功于 KL。

KL 分支重建 Soft4 仍比自身起点下降，但末尾比无 KL 对照高约1.72%。严格硬重建均成功，说明本轮观察到了有限的重建目标与方差正则之间的交换。

起点大量方差梯度被下限截断，但 KL 分支末尾触底占比已降至约0.43%和14.75%。Kσ 的梯度并非全被截断；本轮也不只是均值正则化有效。仍有部分截断，且 σ 依然很小，不能据此宣称更强 KL 或接近单位方差时也已稳定。

β 在开跑前固定：首个更新β=0，第50个更新到1e-4，之后保持。全局梯度不占主导，但在 logvar 组内与重建梯度处于相近量级。两支均200/200步发生 clip，裁剪系数中位数分别约0.5931和0.5440；原 global clip=1 没有更改。

验收使用原两 mesh 同一次 packed forward。实际 Face 从该次预测 Edge 图枚举，阈值0。所有检查点及所有监控/终检噪声的四项FP/FN均为0；小mesh Edge TP1152、Face TP768；大mesh Edge TP7719、Face TP5146。监控集重复使用不等于额外独立重复试验，最终新增50组提供的是有限样本证据，不是对全部高斯噪声的保证。

每一步保留四项 reconstruction loss、KL分解、β、total、五组实际更新、preclip梯度、clipping coefficient、后验/clamp与实际噪声幅度。完整计数与 margin 在各检查点 JSON 中，50次验收逐次保存在 JSONL 中。少数梯度检查点是参数状态0、20、50、100、199，均在相应更新前独立求梯度；没有增加训练步数。
