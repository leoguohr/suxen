# 可比性

- 不加载CAD B19356、Face-only末尾、老师模型或旧72/74模型。
- 输入原100条数组不重新量化、归一化、重排或修复。
- 比较原评分、Hard4及负采样函数的AST一致；native_models.py SHA一致。
- Face评价只使用预测Edge图的完整唯一clique；不补GT候选，缺候选GT计FN。
- 只有同一不可变checkpoint的全部100条完成才能生成正式micro-F1与严格成功数。
- 当前没有真实GPU训练/重建结果，不可宣称达到0.997或100/100。
- 每1000次有效更新评价是持续训练指令后的执行默认节奏，不是历史CAD预算。
