# CAD50收敛曲线对齐

当前XYZ＋Graph前置LN分支仍使用V2骨干：Decoder每块完整FFN、Graph GELU、Encoder GELU、无bias邻居投影。它不等于历史完整A结构。当前四格末尾成功样本全部是8顶点CAD，困难16条仍均未严格成功。

历史同配方A/B对照在2000步的实际Face F1分别18.615%/19.054%，严格15/50、21/50；当前XYZ前置为18.764%、15/50，Fourier后置为20.843%、18/50。当前数值处于历史早期学习阶段的范围。

历史A/B在19356步达到实际Face F1 68.678%/99.526%，严格34/50、38/50。V2在5000步为50.950%、10000步为86.378%、15000步为97.699%。2000步不足以区分最终学习上限与收敛速度；XYZ分支加长后是否追上仍未知。

历史与当前初始化张量不同。历史B正常seed0构造后复制A同名同形状随机参数；当前四格由一个全新V2 seed0初始化共享。历史曲线仅作同数据/同配方的时间尺度参照，不能直接当作当前四格的后续轨迹。

当前单种子四格显示干预收益依赖组合：Fourier条件下后置LN使Edge F1提高15.57个百分点；XYZ条件下后置LN使Edge F1降低4.07个百分点。该观察不等于重复种子统计显著，也未证明历史唯一根因。

计算上，G(h)=W_self h+W_neighbor mean_neighbors(h)。前置分支为h+GELU(G(LN(h)))；后置为h+GELU(LN(G(h)))。LN与混合不交换，节点尺度在邻域混合中的作用、消息进入GELU的分布及反向路径都发生变化。Fourier改变可用位置基函数与输入尺度，因此有产生交互的合理机制；当前没有层内测量证明其中哪个机制主导。
