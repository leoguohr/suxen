历史B的实际Face F1在2000、5000、10000、19356步分别约为0.191、0.510、0.864、0.9953。它在10000步仍为大样本0/16严格成功；19356步为全体38/50、大样本6/16。因此，2000步与历史长训终点的巨大差距首先包含训练时长混淆，不能据此认定当前V2丢失学习能力；大样本strict也不能作为早期淘汰门槛。

当前大样本候选覆盖率约4.4%–14.4%，漏面中约94%–98%属于预测边图未形成候选三角形。候选缺失是已观察到的主要漏面来源，不是优化根因的证明，也不表示Face head已经学好。

待检验的机制假说包括：训练不足；初始化影响收敛速度；Fourier与Graph/LN顺序通过消息尺度、分布和梯度路径产生交互。XYZ-only保留39列投影、将36列Fourier输入置零，因此Fourier干预同时改变表示与输入尺度，不能独立归因为高频信息。现有结果没有指定唯一主导机制。

## 3. 最终预算与执行协议

最终采用四格共同终点，既检验收敛进展，也保留完整的交互比较。此前建议的“先续基线”是节省预算的替代路径，不作为本次已采纳协议中的额外阶段或额外预算。

| 项目 | 固定要求 |
|---|---|
| 分支 | Fourier-post、Fourier-pre、XYZ-post、XYZ-pre；不新增其他因素或种子 |
| 父状态 | 各自完整2000步模型、Adam、RNG及采样游标；不得在分支间复制训练后模型或Adam |
| 每支预算 | 新增8000次optimizer更新，目标累计10000步 |
| 总新增预算 | 四支合计32000次optimizer更新；不是每支32000步 |
| 样本曝光 | 每次5条，每UID从200次增加到1000次，即每UID新增800次 |
| 资源 | 仅GPU0，按共同检查点轮转各支；GPU1留给其他任务 |
| 配方 | LR继续1e-4，不重新warmup；保持数据、顺序、负采样、损失、累积与数值执行配方 |
| 源码 | 独立续训目录记录入口、实际执行代码和来源哈希；不热改父实验源码，不触碰fixed100或diffusion |

四支RNG相同只证明随机状态配对，不意味着模型或Adam相同。按累计更新匹配UID顺序及负例哈希；任何执行方式变更均须有相应等价性证据，不能只依据配置文字认定一致。

预算同时记录有效模型步数与实际执行的optimizer更新。重放或丢失的更新计入实际消耗，不通过重启扩大每支新增8000、总新增32000的上限。若故障后无法在上限内到达共同10000步，以预算上限优先，报告实际共同终点与未完成原因，不自动补预算。

## 4. 评价点与必要指标

完整评价点固定为：恢复后的2000，以及3000、4000、5000、7500、9000、10000。恢复2000步的零更新门槛已由主代理报告通过。10000步是主终点；5000步用于判读，不按成绩淘汰分支。

每个评价点均须保存：

1. 全50及固定大样本16的Edge、实际Face TP/FP/FN和micro-F1；实际Face必须由预测Edge图完整枚举候选后评价。
2. GT面候选覆盖率、Face FN_missing/FN_present和实际候选数量。覆盖率定义为`1 - FN_missing / GT面总数`，核对`Face FN = FN_missing + FN_present`。
3. 当次checkpoint的strict、成功UID及各UID结构错误。固定报告分母50与16，另按8点24条、12–16点10条、66–274点16条分组。
4. 训练loss、梯度裁剪比例、实际参数更新量及采样/参与计数，用于检查优化状态；它们不能代替结构指标。

同一步数分别报告两种编码下的LN顺序收益、两种LN顺序下的编码收益，并计算交互：

`I_Q(t) = [Q(Fourier-post,t) - Q(Fourier-pre,t)] - [Q(XYZ-post,t) - Q(XYZ-pre,t)]`

Q的方向须明确，例如F1或覆盖率越高越好。主要报告固定终点差值，同时报告2000→5000、5000→10000和9000→10000的变化及波动。不得用最佳checkpoint替代主终点，不得合并不同checkpoint的成功UID。

## 5. 停止条件

- 达到累计10000有效步或新增实际更新硬上限即停止，不自动续到15000或20000。
- 状态/采样不一致、非有限loss或梯度、评价不完整时暂停该共同阶段验收，保留现场；不把缺失评价当作通过，不让其余分支无界越过该共同阶段。
- 不因5000步未达到历史0.510、大样本仍0/16、strict暂时下降或短期F1回落，单独提前淘汰某格。
- 不临时改变LR、负例、结构、评价阈值或预算来补救表现。
- 若末段仍在改善，结论是尚未收敛，不是自动追加预算的依据。

## 6. 高层判读与归因上限

| 结果 | 允许的判读 |
|---|---|
| 当前Fourier-post明显接近历史B的同期表现 | 支持训练时长不足解释此前的大差距；历史10000步0.864是参照，不是硬及格线，也不是初始化等价的证明 |
| 四格差距随训练缩小 | 支持2000步差异主要体现收敛速度；仍需检查大样本与错误分解是否一致改善 |
| 同预算下差距持续或交互反转 | 说明此初始化、数据和预算下的组合效果具有训练阶段依赖；不能外推最终容量或统计显著性 |
| 当前Fourier-post在10000步仍明显落后历史B | 初始化或执行差异仍待区分，不能直接归罪Fourier/LN；本轮停止并报告 |
| 末段仍明显改善 | 尚不足以判断最终上限，保留未收敛结论 |

本轮不自动追加初始化桥接、不做更多因素扫描。如后续仍需解释基线同期落后，只能另行提出有明确预算的单一初始化对照；不得中途覆盖2000步模型的部分参数并称为初始化实验。

本轮的成功标准是：在可信恢复、固定曝光和预算下，取得四格完整、可追溯的同预算收敛比较，区分学习进展与严格成功，并诚实保留初始化及机制归因的不确定性。不能据此宣布历史唯一根因、全部CAD严格成功或fixed100问题已解决。
