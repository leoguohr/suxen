## 执行设置与接续

从C累计3800开始，D2总预算3600不变；lr=1e-5、weight_decay=0、clip=1、累积8、BF16。每个micro独立随机时间和噪声，两个物体各9层轮转；训练时VecSet每micro重新前向。生成20步Euler、占据阈值0.5；完整树使用自身上一层输出的parents，无GT替换、top-k或强制非空。
有效日志由原实例1..1200、第二实例1201..3000、第三实例3001..3600组成。原1201..1206与原3001..3030日志仍保存在原snapshot内，因实例丢失后重放而不再计入有效更新；36次更新的实际UID/depth/time/noise逐项一致。两次恢复均核验模型/Adam/RNG和84份开发数组。
