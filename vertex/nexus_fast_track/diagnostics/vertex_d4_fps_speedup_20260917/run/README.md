# D4 固定点云 FPS 复用加速

唯一计算修改：四份固定点云各计算一次 FPS 索引，每个 microbatch 复用索引。VecSet 的可学习特征每次重新计算，继续联合训练。模型参数、Adam、RNG、学习率、loss、8 次累积、7200 总预算及每400步开发评估不变。

基准：修改前第2885步附近100步平均4.304414秒/更新。训练并行运行时，A100独立 FPS 测量平均0.081724秒/次；8次约0.654秒。该分项测试不是端到端加速结论。

验证：本地18项测试通过。CPU测试覆盖有/无激活重计算下3次Adam更新、每次8次累积，前向损失、全部参数梯度、参数与Adam状态逐元素一致，VecSet梯度非零。服务器执行同一测试函数的CUDA/BF16版本，两种重计算设置均通过。服务器pytest入口因已有pluggy版本不兼容无法导入，使用AST移除pytest导入/参数化装饰器后直接调用同一测试函数，未改环境依赖。
